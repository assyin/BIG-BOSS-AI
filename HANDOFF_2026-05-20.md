## 🧠 Décisions importantes (à ne pas re-débattre)

1. **TTS darija paused** — Aucun TTS commercial (ElevenLabs, Gemini, Azure ar-MA, OpenAI) ne fait du vrai darija dialectal. À reprendre soit avec **Cartesia voice cloning**, soit avec **audios pré-enregistrés influenceur** (60-100 phrases clés). Memory: `project_tts_paused.md`.

2. **EF Core jsonb `List<T>.Add()`** — Ne détecte pas la mutation. Toujours `reassign new List<T>(existing) { value }`. Fix appliqué dans `LogSetAsync` + `BuddyProfileConfiguration` doit déclarer `HasColumnType("jsonb")` pour `List<string>`.

3. **Web Share API + fallback** — RN `Share.share()` est no-op en web. Utiliser pattern : navigator.share → wa.me URL → clipboard. Implémenté dans grocery-list, community/index, community/post.

4. **Mock mode Cloudflare Stream** — Sans `BBF_CF_STREAM_API_TOKEN`, retourne URL Mux test HLS pour permettre dev sans payer ($5/mois). Activation prod = 3 env vars.

5. **Modération IA Claude inline** — Haiku rapide+cheap, fail-open (si Claude indispo, on publie). Appliqué dans `CreatePostAsync`, `CommentAsync`, `LiveChatHub.SendMessage`. Auto-mute si `toxicityScore > 0.85`.

6. **Algo matching buddies** — Scoré 0-100 (ville+40, salle+20, goals+5/overlap, slots+10/overlap, niveau+10, nouveau+5). Auto-accept mutual match dans `RequestConnectionAsync`.

7. **OWASP middleware** — 6 headers sur toutes responses (HSTS, X-Content-Type-Options, X-Frame-Options DENY sauf /hangfire, Referrer-Policy, Permissions-Policy, CSP sur /api).

8. **Cache Redis fail-open** — `NoOpCacheService` registered si Redis down → DI ne crash plus. Cache appliqué : `/api/exercises` liste 1h + détail 24h.

9. **Convention enum backend** — Backend .NET retourne enums en int, frontend doit mapper (cf `mapProgrammeStatus` int→string).

10. **8 bugs device fixés en Sprint 3 smoke** — Tous documentés dans `SPRINT_3_FINAL_REPORT.md`. Principaux : CORS LAN, EF jsonb List, JSON cycles, status int→string, web Share fallback.
